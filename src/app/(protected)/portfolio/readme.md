# portfolio folder readme
수정일: 2026-06-10
- 기존 퍼블릭 블로그 영역에서 물리적으로 분리된 포트폴리오 전용 라우트 폴더입니다.
- `(protected)` 그룹 하위에 위치하여, 추후 방문자 비밀번호 인증 등의 보안 레이어를 쉽게 적용할 수 있도록 설계되었습니다.

## File list
- `page.tsx`: 포트폴리오 메인 홈 페이지입니다. `getAllPosts('portfolio')`를 통해 포트폴리오 게시물 목록을 가져오고, `BlogStats` 컴포넌트로 관련 통계(게시물, 내 스킬 개수, 조회수, 좋아요)를 렌더링합니다.
- `about/page.tsx`: 포트폴리오용 'About Me' (자기소개) 콘텐츠가 위치할 스켈레톤 라우트입니다.
- `[category]/page.tsx`: 포트폴리오 카테고리(예: project, myskill, decision 등)별 게시물 목록 페이지입니다. 공용 `PostList` 컴포넌트에 붉은색 테마(`theme="portfolio"`)를 전달하여 블로그와 통일감 있는 UI를 제공합니다.
- `[category]/[...id]/page.tsx`: 포트폴리오 개별 게시물 상세 페이지입니다. 블로그 상세 페이지와 완벽하게 동일한 마크다운 렌더링(구문 강조), 반응형 목차(TOC), 조회수 백그라운드 집계(`ViewTracker`), 좋아요 기능(`LikeButton`)을 지원합니다.

## 주요 특징
- **UI 및 로직 재사용 (DRY 원칙)**: 물리적인 URL(`/portfolio/...`)과 보안(Protected) 영역은 분리하되, 화면을 그리는 `PostList` 컴포넌트와 상세 페이지 데이터 페칭 로직은 기존 퍼블릭 블로그의 코드를 100% 재사용하여 유지보수성을 극대화했습니다.
- **안전한 URL 라우팅**: 게시물 클릭 시 `slug`에 포함된 공백이나 특수문자로 인한 라우팅 이탈(퍼블릭 블로그로 연결되는 현상)을 방지하기 위해 `encodeURIComponent` 기반의 안전한 URL 처리 로직이 적용되어 있습니다.
