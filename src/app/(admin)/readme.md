# admin folder readme
수정일: 2026-06-20
- 블로그 관리자 전용 대시보드 및 관리 페이지가 위치한 Next.js App Router의 `(admin)` 라우트 그룹입니다.

## 파일 목록
- `layout.tsx`: 관리자 페이지 전용 최상위 레이아웃입니다. 일반 사용자가 보는 GNB(헤더)나 Footer를 제외하고, 관리자 인터페이스에 맞는 독립적인 뷰포트와 스타일을 제공하기 위해 사용됩니다.
- `admin/page.tsx`: 관리자 대시보드의 메인 페이지입니다. 전체 게시물 수뿐만 아니라 전체 방문자/조회수/좋아요 수 및 당일(Today) 기준의 상세 통계 카드를 제공하며, PostgreSQL 데이터베이스에서 조회한 데이터를 클라이언트 컴포넌트(`PostListClient`)로 전달하여 다중 선택 및 일괄 수정이 가능한 데이터 테이블을 렌더링합니다.
- `admin/property/page.tsx`: 전역 프론트매터 속성(Property) 목록과 각 속성의 사용 횟수를 확인하고, 새로운 속성을 추가/삭제/이름 변경(Rename)하거나 **전역 필수 속성(Essential)** 여부를 토글하여 설정할 수 있는 속성 관리 페이지입니다.
- `admin/template/page.tsx`: 카테고리별로 게시물을 작성할 때 필요한 프론트매터 속성(이름, 타입, 필수 여부 등)을 템플릿 단위로 추가하고 매핑하여 관리할 수 있는 페이지입니다.
- `admin/write/page.tsx`: 신규 게시물을 작성하는 페이지입니다. 서버 액션을 통해 템플릿 목록과 전역 필수 속성(`is_essential`)을 불러와 `PostEditor` 컴포넌트에 전달하여 입력 폼을 동적으로 구성하며, 게시물 데이터를 DB에 저장합니다.
- `admin/edit/[...slug]/page.tsx`: 기존 게시물을 수정하는 페이지입니다. 카테고리 계층을 포함한 경로(Catch-all)를 처리할 수 있도록 설계되었으며, DB에서 기존 게시물의 데이터를 불러와 폼에 채운 뒤 수정을 진행할 수 있습니다.
- `admin/login/page.tsx`: 관리자 페이지 접근 시 거쳐가는 로그인 페이지입니다. Server Action을 통해 비밀번호를 검증하고 인증 쿠키(`admin_auth`)를 발급합니다.
- `admin/visitor/page.tsx`: 사이트 전역의 방문 기록(Unique Visitor), 실시간 접속 정보 및 차단 목록(Exclusion Rules)을 확인하고 제어할 수 있는 방문객 관리 페이지입니다. 데이터베이스의 실시간 데이터와 부드러운 애니메이션이 가미된 양방향 모의 대시보드(차트, 토스트 피드백, 필터링 등)를 통합해 직관적인 트래픽 관리를 지원합니다.

## 주요 특징 및 계획(TODO)
- **격리된 레이아웃**: `(public)` 영역과 완전히 분리된 레이아웃을 사용하여, 일반 방문자와 관리자의 사용자 경험(UX)을 명확히 분리했습니다.
- **데이터베이스 연동 (JSONB 스키마)**: `posts` 테이블의 단일 JSONB 컬럼(`properties`)을 쿼리하여 동적 메타데이터를 유연하게 관리하고 통계와 목록을 렌더링하도록 개편되었습니다.
- **인증 시스템(Auth)**: Next.js의 미들웨어(`src/middleware.ts`)를 도입하여 `/admin` 경로 하위로 접근하는 모든 트래픽을 가로챕니다. 인증 쿠키가 없으면 로그인 페이지로 자동 리다이렉트 되며, 하드코딩된 비밀번호를 검증하여 보안을 유지하고 있습니다.
