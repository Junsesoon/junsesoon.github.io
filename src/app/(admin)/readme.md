# admin folder readme
수정일: 2026-05-28
- 블로그 관리자 전용 대시보드 및 관리 페이지가 위치한 Next.js App Router의 `(admin)` 라우트 그룹입니다.

## 파일 목록
- `layout.tsx`: 관리자 페이지 전용 최상위 레이아웃입니다. 일반 사용자가 보는 GNB(헤더)나 Footer를 제외하고, 관리자 인터페이스에 맞는 독립적인 뷰포트와 스타일을 제공하기 위해 사용됩니다.
- `admin/page.tsx`: 관리자 대시보드의 메인 페이지입니다. 전체 게시물 수 통계를 보여주고, 실제 PostgreSQL 데이터베이스와 연동하여 전체 게시물 목록을 데이터 테이블(Data Grid) 형태로 제공합니다.
- `admin/write/page.tsx`: 신규 게시물을 작성하는 페이지입니다. 재사용 가능한 `PostEditor` 컴포넌트를 활용하여 폼(Form) 인터페이스를 제공하며, `components/actions.ts`의 서버 액션(Server Action)을 호출하여 실제 DB에 데이터를 저장합니다.
- `admin/edit/[...slug]/page.tsx`: 기존 게시물을 수정하는 페이지입니다. 카테고리 계층을 포함한 경로(Catch-all)를 처리할 수 있도록 설계되었으며, DB에서 기존 게시물의 데이터를 불러와 폼에 채운 뒤 수정을 진행할 수 있습니다.

## 주요 특징 및 계획(TODO)
- **격리된 레이아웃**: `(public)` 영역과 완전히 분리된 레이아웃을 사용하여, 일반 방문자와 관리자의 사용자 경험(UX)을 명확히 분리했습니다.
- **데이터베이스 연동**: `src/infra/db.ts`의 `query` 유틸리티를 사용해 실제 데이터베이스(`posts` 테이블)에서 메타데이터를 쿼리하여 통계와 목록을 동적으로 렌더링하도록 구현되었습니다.
- **인증 시스템(Auth) 도입 예정**: 현재는 단순 라우팅과 정적 페이지만 구현되어 있어 누구나 `/admin` 경로 혹은 `footer`에서 `junseo`를 클릭하여 접근할 수 있습니다. 추후 인가받은 관리자만 접근할 수 있도록 Next.js 미들웨어(Middleware) 또는 세션 검증 로직을 추가할 계획입니다.
