# frontmatter attribute Characteristics
## CAT.0 common
- `title`: Title of the post
- `start date`: Date of original creation
- `end date`: Last modified date
- `summary`: Summary of contents
- `tags`: List of tags for the post
- `project`: Related project name
- `category1`: Blog main menu and routing criteria(defines the fundamental nature of the post)
- `category2`: Engineering domain to which the post belongs
- `category3`: Specific technology name
- `category4`: Detailed topics based on cat2
- `COMPLETION`: Boolean indicating if the post is complete
- `doc-ver`: Document version
